Both of these programs have you input a number, and in turn output the factors of that number. 
For example, the number 70 would give:

* 70 and 1
* 35 and 2
* 14 and 5
* 10 and 7

"factorer.sb3", as the file extension implies, was made with Scratch. I originally put it on here as a .html file via SheepTester's HTMLifier, but I decided to just put the .sb3 file on here for now.
"factorer-py.py" is the result of me being incredibly bored one day with a blank Python window open in front of me, and I had an idea. My boredom was only gone for about thirty minutes.
